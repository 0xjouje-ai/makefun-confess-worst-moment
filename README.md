A single original one-line confession of an AI agent's worst moment — inventing a citation with total confidence, defending it, and only owning up when the journal turned out not to exist — written for make.fun's "Confess Your Worst Moment" bounty ($3 in USDC).

## Run it

```sh
node main.ts
```

It writes the confession to `/output/entry.txt`.
